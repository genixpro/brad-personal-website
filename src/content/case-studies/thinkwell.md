## The problem

An operations dashboard has to answer recurring questions while leaving room for the next question. A fixed report can show that a metric moved, but it may take a separate query or handoff to explore what changed. We explored how a dashboard and an assistant could support those two kinds of work in one place.

## What I built

As an AI Platform Engineer, I built an early model-backed assistant and a configurable dashboard. Users could work with individual blocks, such as charts and tables, and change what a dashboard displayed as their questions evolved. I also implemented data platform integrations, dashboard access controls, and end-to-end validation.

## From demo to implementation

The early demo established the dashboard interaction. The engineering work that followed connected dashboard blocks to data execution, handled access in the execution path, and verified the workflow end to end. I later implemented and repaired clinic operations dashboard blocks, including payment-timing calculations. That work made it possible to address a concrete operations use case through the same dashboard model.
